一需求来源分析

1.1 项目概述

ONETECH 是一个面向中小商家的全功能电商平台，提供从商品上架、订单处理到营销推广的一站式解决方案。采用 Next.js 14 + TypeScript 全栈技术构建，覆盖管理后台与 PC 商城两大端。

说明：功能需求参考了 CRMEB 开源商城（Apache-2.0 协议），全部代码独立重写，使用完全不同的技术栈（PHP → TypeScript，Vue → React）。

六代码质量约束

规则阈值
单文件行数≤ 500 行（400 行预警，1000 行禁止）
单函数行数≤ 40 行
单组件行数> 200 行评估拆分
文件职责一个文件只做一件事（SRP）
视图/逻辑分离禁止 God Component，业务逻辑抽取到 hooks/services
命名必须揭示意图，禁止 data/info/helper/temp 作唯一名称
重复代码提取为 Hooks / Utils / Service

九风险与决策记录

决策点选择理由
ORMPrismaTypeScript 原生支持，自动生成类型，迁移工具完善
数据库PostgreSQL功能更强大，JSON 支持好，适合复杂查询
认证方案自研 JWT (jose 库)Admin + 商城双端隔离，比 NextAuth 更灵活
状态管理Zustand轻量，无 Provider 嵌套，适合中等复杂度
DIY 装修分阶段实现拖拽编辑器复杂度高，放到 Phase 3
支付集成Mock 先行先用模拟支付，后续接入真实支付渠道
微信相关暂缓Web 端优先，微信公众号/小程序对接放最后
