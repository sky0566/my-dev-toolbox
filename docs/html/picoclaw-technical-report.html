2.2 项目背景

Sipeed（矽速科技）是全球知名的 RISC-V 硬件厂商，其产品包括 LicheeRV Nano、MaixCAM 等超低成本开发板。PicoClaw 的诞生源于一个朴素的想法：如果我们的 $10 硬件能跑 Linux，为什么不能跑 AI Agent？

PicoClaw 受 NanoBot 项目启发，但并非 fork——而是用 Go 语言从零重写。最特别的是，95% 的核心代码由 AI Agent 自身生成，人类工程师主要做架构设计和代码审查。这套"AI 自举（Self-Bootstrapping）"的开发模式本身就是一次前沿工程实践。

类比理解：如果 ChatGPT 是运行在数据中心的"重型卡车"，PicoClaw 就是可以装在口袋里的"电动滑板车"——它不能拉货，但能让你灵活地穿行于城市的每个角落。

3.2 技术选型解析

技术决策选择原因
编程语言Go 1.25+静态编译、跨架构交叉编译、优秀的并发模型（goroutine）、无运行时依赖
二进制分发单一可执行文件用户无需安装任何依赖，下载即用。GoReleaser 自动构建多平台产物
配置格式JSON（config.json）结构化、易于程序解析、支持环境变量覆盖
Web UI内嵌 Launcher浏览器界面可视化配置，零前端依赖
消息协议统一 Gateway所有渠道共享同一网关端口（18790），简化部署
内存存储JSONL + Markdown极低开销的持久化方案，无需数据库
为什么选 Go 而不是 Rust？
Go 的编译速度远快于 Rust、交叉编译更简便（GOOS/GOARCH 一行搞定）、goroutine 天然适合处理多路消息并发。对于 PicoClaw 这样的 I/O 密集型应用，Go 的性能已经远超需求，而开发效率的提升是决定性的。

🔗 特性三：MCP 协议原生支持

🧠 特性四：智能模型路由

PicoClaw 支持基于规则的模型路由——简单问题自动发往轻量模型，复杂问题走高端模型，节省 API 成本。

用户问 "今天天气怎么样？"
  → 路由规则匹配：简单查询
  → 发送至：Haiku / DeepSeek-V3（低成本模型）
  → 成本：≈ $0.0001

用户问 "帮我分析这段代码的性能瓶颈"
  → 路由规则匹配：复杂推理
  → 发送至：Claude Opus 4.6 / GPT-5.4（高端模型）
  → 成本：≈ $0.05

还支持通过 bindings 配置将不同渠道、不同用户的消息路由到不同的 Agent 实例，实现多租户隔离。

🤖 特性五：完整的 Agent 能力

PicoClaw 不是简单的聊天转发器。从 v0.2.1 开始，它具备了完整的 AI Agent 能力：

🔍
网页搜索

支持 DuckDuckGo（免费）、Brave、Tavily、百度等 7 种搜索引擎，Agent 可自主上网查找信息。

💻
代码执行

Agent 可在沙箱环境中执行代码，进行数据处理和计算。支持安全策略配置。

⏰
定时任务

内置 Cron 调度器，支持一次性提醒、周期性任务、Cron 表达式。任务持久化存储。

🎯
技能系统

通过 SKILL.md 文件加载模块化能力。支持从 ClawHub 安装社区技能。

👁️
视觉管线

直接发送图片和文件给 Agent，自动 base64 编码后调用多模态 LLM 进行分析。

🧬
子 Agent 编排

v0.2.4 新增 SubTurn 架构，支持子 Agent 并发控制和生命周期管理。
